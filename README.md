# 🚀 ResolveAI

### AI-Powered Intelligent Incident Management & Automated Resolution Platform

ResolveAI is an AI-powered incident management platform that helps organizations **detect, classify, investigate, and resolve IT incidents faster** using Machine Learning, NLP, semantic search, and knowledge-based recommendations.

##  ✨  Features

* 📝 Incident creation and management
* 🤖 AI-powered incident classification
* 🔍 Intelligent incident investigation
* 🧠 ML-based analysis and recommendations
* 🔎 Semantic search using vector embeddings
* 📚 Knowledge-based resolution assistance
* 📊 Incident tracking and workflow management
* 🌐 Modern web-based dashboard

## 🏗️ Architecture

```text
React + Vite
     ↓
Django REST API
     ↓
PostgreSQL
     ↓
AI / ML Services
     ├── XGBoost
     ├── BERT / NLP
     ├── FAISS
     └── RAG
```

## 🛠️ Tech Stack

**Frontend:** React.js, Vite, JavaScript, HTML, CSS

**Backend:** Python, Django, Django REST Framework, FastAPI

**Database:** PostgreSQL, Django ORM

**AI / ML:** XGBoost, BERT / Sentence-BERT, NLP, FAISS, RAG

**DevOps:** Docker, Docker Compose, Git, GitHub

## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/YOUR-USERNAME/ResolveAI.git
cd ResolveAI
```

### Backend

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Docker

```bash
docker compose up --build
```

> Configure the required environment variables and API keys before running the application.

## 🎯 Goal

ResolveAI aims to reduce **incident resolution time (MTTR)** by combining intelligent classification, AI-assisted investigation, and knowledge-based resolution recommendations into a single platform.
